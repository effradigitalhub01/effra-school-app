# Effra School System (Effra Academy)

School management web application built for Pi Network and Pi Browser access, using Pi-exclusive authentication (`src/pi.ts`), core business logic (`src/logic.ts`), and user interface components (`src/ui.tsx`).

## Live URLs
- **Vercel:** https://effra-school-app.vercel.app
- **PiNet Subdomain:** https://effradigitalhub0162.pinet.com

## Project Structure
- `src/logic.ts` — Core class, fee, grading, and school management logic
- `src/ui.tsx` — Main application interface and state management
- `src/pi.ts` — Pi SDK authentication flow (email/password login removed)
